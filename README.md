# 🐍 Snake Game (Python Turtle Edition)

This is a classic Snake game implemented in Python using the `turtle` graphics module. The goal is to collect food, grow your snake, and avoid colliding with the walls or yourself.

## 🎮 Features

- Classic Snake movement with arrow keys
- Food that randomly appears on the screen
- Score tracking with a persistent high score (stored in `data.txt`)
- Collision detection for walls and snake body
- Smooth gameplay using screen updates and delays

## 💾 High Score

- The high score is saved in `data.txt`.
- If the snake dies and your score is higher than the high score, it gets updated.

## 🛠️ Dependencies

Only the standard Python library is used:
- `turtle`
- `random`
- `time`

No external packages are required.
